Project 1 · Python, PyTorch, Next.jsDone

Shock Lab

A portfolio stress-testing engine. It takes a macro shock, returns a return distribution for 24 assets, and optimizes a portfolio against it. The neural model did not beat the linear baseline, and the write-up says so.

PyTorch · pandas · NumPy · SciPy · cvxpy (HiGHS) · FastAPI · Pydantic · pytest · Next.js · TypeScript · D3.js · Framer Motion · WebAssembly · GitHub Actions
Live demo Source on GitHub
Problem

Show how a 24-asset portfolio responds to a macro shock such as an oil spike or a rate jump, then build a portfolio that limits tail losses.

Data

24 assets: 19 US ETFs (equities, sectors, Treasuries, high yield, gold, oil, airlines) and 5 TSX names. 5 FRED factors: WTI oil, 10-year Treasury yield, broad USD index, VIX, and Moody’s Baa−10Y credit spread. Daily from 2007, built into 10-day windows.

Approach
  • Baseline: rolling 3-year OLS factor betas with multivariate Student-t residuals.
  • Neural model: a PyTorch mixture density network with 5 Gaussian components over all 24 returns, conditioned on the factor shock plus regime features (VIX level, 60-day average cross-asset correlation). Negative log-likelihood loss, early stopping, yearly walk-forward refits.
  • Risk engine: 95% VaR, CVaR, per-holding CVaR contributions, factor attribution, and replays of 5 historical shocks.
  • Optimizer: Rockafellar–Uryasev CVaR minimization as a linear program in cvxpy. Long-only, 15% cap per asset, minimum expected return, a minimal-turnover mode, and a CVaR-versus-return frontier.
24 assets + 5 factors→10-day windows→Linear baseline/Neural model→10,000 scenarios→VaR · CVaR · attribution→CVaR optimizer
Evaluation
  • No lookahead: every model is fit only on windows that ended before the evaluation date.
  • Date-based splits: train through 2017, validation 2018–2019, test 2020 onward, scored on non-overlapping windows.
  • Monthly walk-forward backtest, 2018 to Oct 2026, net of 10 bp transaction costs, against equal weight, 60/40 and minimum variance.

What didn’t work
  • The neural model did not beat the linear baseline on likelihood. The baseline led in all 5 historical events.
  • The CVaR strategy cut the worst drawdown but trailed equal weight on return, and trailed both equal weight and minimum variance on Sharpe.
  • Data issues, documented in the repo: FRED now serves only 3 years of the ICE BofA high-yield spread, so credit uses Baa−10Y. The negative WTI price of April 2020 is treated as missing.

Project 2 · Python, PyTorch, Hugging FaceIn progress

Earnings Lens

An NLP model for how a stock reacts to an earnings release. It is designed to show the sentences behind each prediction and to cite its sources when an LLM extracts guidance changes.

Python · PyTorch · Hugging Face · Claude API · SEC EDGAR
Plan
  • Collect: parse earnings press releases from SEC EDGAR 8-K filings, 2015–2025, aligned with each stock’s 3-day market-adjusted return.
  • Model: fine-tune FinBERT in PyTorch to classify the reaction on a time-based holdout, against a TF-IDF logistic regression baseline.
  • Explain: integrated gradients highlight the sentences behind each prediction.
  • Extract: an LLM layer pulls guidance changes and beat or miss signals with sentence-level citations, scored against hand-labelled releases.
Status

Design stage. No results yet, so none are shown. They will go here when they are measured, including the disappointing ones.
