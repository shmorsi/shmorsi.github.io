Earnings Lens

Research idea · Design stage

Exploring how NLP can connect an earnings release to a stock’s reaction, with the source sentences behind each prediction.+

A proposed research project using Python, PyTorch, Hugging Face, the Claude API and SEC EDGAR.

  • Parse 2015–2025 earnings press releases from SEC EDGAR 8-K filings and align them with 3-day market-adjusted returns.
  • Compare a fine-tuned FinBERT model against a TF-IDF logistic regression baseline on a time-based holdout.
  • Use integrated gradients to show which sentences contribute to each prediction.
  • Extract guidance changes with an LLM, cite the source sentences, and score against hand-labelled releases.

Design stage. No model results have been measured yet.
