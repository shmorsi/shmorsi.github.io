ATLAS

How does a cost shock in one industry spread through the global economy?

A local-first economic research terminal that connects country data, production networks and reproducible models. Explore an economy, trace its dependencies, run a hypothetical cost shock through them, and inspect the evidence behind every number. It runs on your own machine with bundled data; nothing is hosted.

Problem

Make global economic data and the dependencies between industries understandable, while keeping three things clearly apart: observed history, hypothetical scenarios and learned predictions.

Data pipeline

  • Validated seven Organisation for Economic Co-operation and Development (OECD) Inter-Country Input-Output (ICIO) tables and aggregated 4,050 country-industry nodes into 405 nodes across 81 areas and five sectors.
  • Preserved published accounting discrepancies, checked source file hashes and independently verified sampled transaction totals against the raw tables.
  • The country atlas adds 42,900 World Bank World Development Indicators (WDI) records from 1960 to 2024 for 177 countries and territories, with every missing value kept explicit and every observation dated.

What I built

  • A 405-node fixed-coefficient cost-propagation engine with direct and indirect effects, numerical residuals and a supplier exposure map. In the Scenario Studio, PyTorch solves and differentiates combined cost scenarios, checked against an independent SciPy solver and against finite differences.
  • Bond calculations, constrained portfolio analysis and walk-forward allocation with drifting weights and repeated transaction costs.
  • 12 saved PyTorch checkpoints, six gated recurrent unit (GRU) models and six graph models, with baselines and chronological evaluation. A release gate replays 60 GRU predictions and 2,430 graph-node predictions and verifies every source and model hash before startup.
  • A single local FastAPI service that serves the interface and the application programming interface (API), an offline map built with MapLibre, and a guided country-exploration journey next to research views with their assumptions and diagnostics.

Validation

  • Release v0.1.2 passed 44 backend tests and a 27-test Chromium browser suite covering combined shocks, exports, live checkpoint replay, failed requests and layouts at 1,440, 820 and 390 pixels wide.
  • Continuous integration (CI) on Ubuntu, macOS and Windows installs the project, runs setup and artifact checks, runs every backend test, verifies model replay and builds the production interface.
  • On my machine, a 405-node scenario takes a median of 11 milliseconds over ten warm local requests. That is a local measurement, not a guarantee under load or on other hardware.

What didn't work

Reported as found
  • The exploratory graph model did not beat ridge regression on its single held-out year, and the interface says so along with the small-sample limitation.
  • The GRU models were not consistently better across random seeds.
  • Production-cost scenarios assume fixed input shares and full cost pass-through; they do not claim causal market returns. OECD dependencies end in 2022.
  • An expanded Scenario Studio for exchange-traded funds and events is a documented future design, not a shipped feature.

Run it locally

Download and extract the release, open its folder, then run npm ci, npm run setup and npm run atlas, and open http://127.0.0.1:8000. Requires Node 22 or later, Python 3.12 or 3.13 and a browser with WebGL2. Installation needs internet access; normal use runs on bundled data.
