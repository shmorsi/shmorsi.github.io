# Sherif Morsi — portfolio

[Visit the portfolio](https://shmorsi.github.io/)

An always-dark, responsive portfolio at the intersection of AI, machine learning and finance. Experience appears before selected projects. Internship and co-op availability covers Toronto and Montréal.

- [ATLAS case study](https://shmorsi.github.io/projects/atlas.html): a downloadable local economic research terminal.
- [Shock Lab case study](https://shmorsi.github.io/projects/shocklab.html): project engineering, evaluation and measured results.
- [Shock Lab demo](https://shmorsi.github.io/shocklab/): browser-based portfolio stress testing.

This is a static GitHub Pages website. Edit `index.html`, the case studies under `projects/`, and shared styles and interactions in `assets/site.css` and `assets/site.js`. Images are actual application captures. No build step or JavaScript framework is required.

To preview locally, run `python3 -m http.server 4173` from the repository root and open `http://localhost:4173`. Pushing `main` publishes through GitHub Pages.
